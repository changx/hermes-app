# Disposable Expo Android JS / Hermes SDK probe

From this directory: `bash run.sh`. Requires Node/npm, pinned read-only Hermes baseline at `/opt/projects/jamie/_worktrees/hermes-agent/hermes-app-p0-baseline` (override `HERMES_BASELINE`), and outbound npm access or warmed cache. Installs lockfile dependencies only under `/home/hermes/.hermes/profiles/jamie/workspace/hermes-app/p0/close-mobile` (override `HERMES_EXPO_DEPS`); local `node_modules` is ignored symlink. No JDK/SDK, cloud build or account. Script stops if free disk is below 20 GiB; npm and export have bounded timeouts.

`run.sh` captures Metro and synthetic channel outputs in `export-android-js.log` and `protocol-test.log`, verifies bundle content and writes `results.json`. Lockfile pins Expo/RN/esbuild and transitive packages. Output `dist/` and `.expo/` are ignored; Metro's `--no-bytecode` is **diagnostic JS only**, not a distributable APK. The exported bundle includes the actual baseline shared SDK, while `protocol-test.cjs` tests that SDK with an in-memory transport, not the plugin HTTP/WS contract. No connection to Hermes, phone runtime, APK, or UI/device quality is tested. See [`docs/p0/close-mobile.md`](../../../docs/p0/close-mobile.md).
