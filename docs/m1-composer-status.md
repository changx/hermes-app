# 输入栏操作和发送反馈

## 本轮决定

- 按 Jamie 反馈，删除输入栏上方的任务工具条。当前话题正在处理时，原发送按钮直接显示「停止」，没有正文也可停止；结束后恢复发送。输入框草稿不受停止影响。
- 排队消息取消入口移到对应消息下；不把 reaction 当作操作按钮。必要批准/回答表单保留。历史窗口外的排队项不再占据常驻工具条。
- 当前正文已按真实待发状态使用灰色，但确认后直接换色，没有过渡，快速确认可能让变化不易察觉。这是代码事实与可能解释，不声称已复现真机现象。
- 确认后正文颜色短暂平滑恢复；不延迟网络发送，不人为维持未确认状态。历史消息首次显示实色，不重播；减少动态效果时直接换色。保持消息 key、尺寸和阅读位置。
