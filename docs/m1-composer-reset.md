# 发送后输入框恢复单行

## 证据与修正

- 用户真机反馈长文发送后输入框仍占多行。App 在 outbox 持久保存成功后将未改动的草稿清空；失败或发送期间新编辑的草稿保留。
- ChatTimeline 多行 TextInput 只有 minHeight 42 / maxHeight 120，正文变空时没有显式高度复位，依赖原生内在尺寸重新测量。未取得该 iPhone 原生测量日志，不能断言具体 UIKit 缓存原因。
- 最小修正：正文长度为零时显式 height 42，有正文时恢复原生自适应与 maxHeight 120。不通过 key 重挂、不调用 blur/focus、不切换 multiline、不设置延时。不处理附件预览或改变发送状态。
- 验收：生产组件长文→清空→重新输入的样式和身份，空值下晚到布局不扩大输入；发送失败/新草稿保护继续通过现有发送回归。完整移动测试、类型检查、双平台导出、公网包检查；iPhone 高度与键盘手感另验。
