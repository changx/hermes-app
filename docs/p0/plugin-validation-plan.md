## 完整检查范围

每项给出状态：实测已有能力 / 实测插件补齐路径 / 源码可行但未实测 / 扩展点不足 / 环境或外部条件阻塞。通过基础单元测试不等于端到端产品功能完成。

### TRANSPORT：插件加载、入口与权限

- T01：正常 plugin manifest/discovery/register 加载；启用/禁用和启动/停止清理。
- T02：客户端 HTTP/WS/RPC 通信入口；现有接口复用与新增入口的扩展方式；实际 loopback 请求。
- T03：未认证、错误凭据、跨身份/profile 访问的拒绝；认证范围和插件全信任边界。
- T04：双端在线订阅和重连；插件通知如何到达连接。
- T05：附件上传/下载、大小/类型/路径边界与授权；不存在完整路径时明确列为插件工作量。
- T06：不能注册的现有核心 RPC/路由及其不修改核心的替代入口。

### HISTORY：项目、内容和持久同步

- H01：Channel/Thread 与已有 Project/session/room 的映射及 CRUD、改名/归档/列表。
- H02：可见历史读取和分页跨 compaction lineage，隐藏内部记录，稳定消息身份。
- H03：持久事件、游标、快照/增量衔接、断线与重启恢复，不依赖有限内存回放。
- H04：发送持久接收和重复提交去重；相同文本的新发送；原子接收与执行边界。
- H05：已读单调游标、未读、搜索；区分已有 API、可由插件持有的元数据及缺口。
- H06：权限/保留策略/历史删除、插件元数据生命周期与卸载，避免复制权威会话数据库。

### EXECUTION：运行、提示与交互

- E01：正常平台插件收发进入 Hermes 的路径；不重写 Agent。
- E02：新 Thread/Session 创建时设置 Channel Description 头部上下文，后续沿用；验证压缩/恢复/续接的保留及线程隔离，不要求每条用户消息或每个请求重新注入原文。已有逐请求字符串检查仅是特定接口的诊断观测，不能直接当成本需求的通过/失败判定。
- E03：客户端全部离线后继续执行；停止、追加/排队、超时与资源所有权。
- E04：stream/final/error 落入可恢复历史；合成执行崩溃/进程重启后的真实边界，禁止盲重跑有副作用任务。
- E05：审批/clarify 双端单次决议、过期/迟到答复、离线恢复。
- E06：cron/后台主动投递至正确 Thread；手机推送入口与 APNs/FCM 真机未验证边界。
