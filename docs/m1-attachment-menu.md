# 附件加号菜单

## 决定与验收

- 输入区只常驻「＋」，点按展开文件、系统相册、拍照、粘贴；选择后收起。使用小型内联菜单，不用额外 Modal 抢输入焦点；不主动收键盘。
- 移除原先显示为空白蓝块的常驻 ClipboardPasteButton。粘贴只在用户选择菜单操作后读取，可能出现系统剪贴板授权提示。图片优先作为附件，文字/URL/富文本的纯文字插入当前光标或替换选区；不是任意剪贴板文件读取，文件仍经选择器。原有输入框系统文字粘贴不变，不宣称长按直接粘贴图片已支持。
- 相册/文件沿用多选、上传与缩略图；拍照仅点按后请求相机权限，无权限用自然语言提示，取消不上传。异步权限/选择结果在切换话题、提交清空、卸载后忽略。
- 保留数量、大小、持久队列与鉴权边界。不改变发送、停止或后端。
- 验证生产菜单回调、多选/取消、相机拒绝/成功/失效、显式粘贴、移动全测/TS/双平台导出。按既有授权仅更新隔离 Expo。iPhone 拍照、菜单和焦点需实机确认。
